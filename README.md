# Rust raytracer

This is essentially the same raytracer as the one in my graphics course at UMN.
The only difference is that I'm reimplementing it in Rust over C, just to
refresh my rusty Rust skills. 

Run with `cargo run -- <in file> <out file>`. 

It's been rewritten up till the point where Phong shading is added. Triangles
will happen sometime in the future.
